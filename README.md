# 💻 Formação Frontend - Aulas Full Stack

Este repositório contém os exercícios, conceitos e projetos práticos desenvolvidos durante o módulo de desenvolvimento Frontend (HTML/CSS, JavaScript, TypeScript e ReactJS).

---

## 🗂️ Estrutura do Repositório

| Diretório | Descrição |
| :--- | :--- |
| **`01. Aula teste/`** | Testes iniciais e configuração do ambiente de desenvolvimento. |
| **`02. Css - Aulas Práticas/`** | Fundamentos de CSS3, estilização, layout (Flexbox/Grid) e responsividade. |
| **`03. Java Script - Aulas Práticas/`** | Conceitos fundamentais de JavaScript (sintaxe, funções, manipulação de DOM). |
| **`04. Java Script Avançado - Aulas Práticas/`** | Recursos avançados do JS (Assincronismo, Promises, Async/Await, ES6+). |
| **`05. Evoluindo com Exercícios - Aulas Práticas/`** | Resolução de desafios práticos para fixação de lógica e manipulação de dados. |
| **`06. ReactJS - Começando/`** | Introdução ao React, criação de componentes, JSX, *props* e *state*. |
| **`07. React - Projeto PrimeFlix/`** | Desenvolvimento de uma aplicação prática consumindo APIs (Projeto PrimeFlix). |
| **`08. Reactjs Domina Firebase/`** | Integração do ReactJS com o Firebase (Autenticação, Firestore, Banco de dados em tempo real). |
| **`09. Evoluindo com TypeScript/`** | Introdução e fundamentos do TypeScript no ecossistema JavaScript. |
| **`10. TypeScript - Interfaces e Types/`** | Modelagem avançada de dados utilizando *Interfaces*, *Types*, *Generics* e boas práticas. |

---

## 🛠️ Tecnologias Utilizadas

* **Linguagens:** HTML5, CSS3, JavaScript (ES6+), TypeScript
* **Biblioteca Principal:** ReactJS
* **BaaS / Serviços:** Firebase (Authentication / Firestore)
* **Gerenciador de Pacotes:** npm / yarn

---

## 🚀 Como Executar Os Projetos

1. **Clonar o repositório:**
   ```bash
   git clone [https://github.com/seu-usuario/nome-do-repositorio.git](https://github.com/seu-usuario/nome-do-repositorio.git)
   cd nome-do-repositorio
    ```
2. **Navegar até a pasta do projeto desejado:**
    ```bash
    cd "07. React - Projeto PrimeFlix"
    ```
3. **Instalar as dependências e executar (para projetos React):**
    ```bash
    npm install
    npm start
    # ou
    npm run dev
    ```
